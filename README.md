# fruler

macOS 屏幕取色、测量与截图标注工具。Flutter 负责历史、设置和标注界面，Swift 负责屏幕采集、浮层、快捷键与系统剪贴板。

## 使用流程

| 工具 | 默认快捷键 | 在屏幕上完成 |
| --- | --- | --- |
| 取色 | `⌘ ⇧ C` | 放大镜定位像素，点击 / Enter 立即复制；Esc 取消 |
| 测量 | `⌘ ⇧ R` | 拖拽后保留尺寸，可移动、缩放和新增选框；Enter 复制当前框并结束；1–4 切换模式 |
| 截图标注 | `⌘ ⇧ X` | 框选后直接在同一个全屏浮层、同一个位置标注，复制 / 保存 / 贴图成功即结束 |
| 剪贴板贴图 | `⌘ ⇧ T` | 图片、文字或 HEX 颜色变成独立置顶贴图 |
| 显示／隐藏贴图 | `⌘ ⇧ V` | 隐藏全部贴图，或恢复已隐藏的贴图 |

取色器、尺子、截图是三个独立工具，各自通过全局快捷键或状态栏菜单启动，会话中不提供跨工具切换。尺子主入口恢复上次使用的测量模式，矩形 / 水平 / 垂直 / 交叉模式只在尺子工具条内切换。状态栏菜单参考 Snipaste 的原生菜单组织：截图 / 取色器 / 尺子为常用工具组（截图优先），剪贴板贴图 / 显示隐藏贴图 / 销毁贴图为贴图组，历史记录 / 设置为管理组，退出单独分组；不为每个测量模式增加菜单入口。

独立取色器和尺子浮层沿用截图工具的深灰表面、蓝色选中态、紧凑图标按钮和小圆角；悬停查看操作说明及快捷键，工具条位于屏幕顶部，尺子的框编辑属性条位于主工具条下方，仅在矩形测量存在框或可撤销操作时显示；工具条按内容收紧，左右内边距 10 pt，按钮间距 6 pt。截图保留像素定位放大镜、颜色及选区尺寸信息，C / M 仍可直接复制，工具栏不另设尺寸复制按钮，也没有完整尺子模式、测量结果列表或跨工具切换入口。

独立工具的内容参考 PowerToys [Screen Ruler](https://learn.microsoft.com/windows/powertoys/screen-ruler) 与 [Color Picker](https://learn.microsoft.com/windows/powertoys/color-picker)：尺子以矩形、水平、垂直和交叉四种测量模式为主，滚轮调整边界容差；取色器顶部显示当前复制格式、放大倍率与采集数量，提供连续取色开关，光标旁显示颜色预览和像素信息，滚轮调整放大倍率。保留当前应用的当场复制流程与多框编辑能力。

完成后关闭浮层并回到原应用，不自动打开主窗口。主窗口是选项窗口，采用 PowerToys 式常驻侧栏，按「常规 / 取色器 / 尺子 / 截图」组织配置和历史；启动只显示一个菜单栏图标，不弹主窗口或 Dock 图标。从菜单可主动打开历史和设置，关闭主窗口后仍可使用全局快捷键。

常规页集中语言、三种屏幕工具和两种贴图操作的全局快捷键、屏幕录制权限与应用信息。每个工具页提供自己的启动入口与快捷键：取色器页管理复制格式模板、连续取色、鼠标动作、放大倍率和颜色历史上限；尺子页管理默认模式、颜色容差和测量历史上限；截图页说明屏幕选区、标注和导出流程，并展示本次运行的截图历史。各页独立滚动，切换页签保留工具配置和历史。

### 截图与标注

工具栏结构和常用交互参考本机 Snipaste 2.11.3 与[官方基础操作](https://github.com/Snipaste/feedback/wiki/基础操作)、[官方快捷键](https://github.com/Snipaste/feedback/wiki/内置快捷键)。

- 选区和标注保留在同一个原生 NSPanel。添加标注后仍可拉动八个边角控制点调整选区；默认模式下拖动空白处移动选区，或用方向键按截图像素微调（选中标注时调整该标注）；⌘ + 方向键扩大对应边界，Shift + 方向键缩小。调整复用冻结快照，不重新录屏。
- 选区前自动预览光标下最上层可见窗口，单击采用该区域，主动拖动改为手动框选；按住 Option 可暂停吸附。窗口跨屏时按所在显示器裁剪并换算到像素边界。当前沙盒版本提供窗口级吸附。控件级检测需先调整发行方案。
- 截图未开始标注时默认显示跟随鼠标的放大镜、颜色、像素坐标与区域尺寸，无需点击取色按钮。框选后，静止时放大镜仅在选区内及边界显示；移动或缩放选区期间持续显示，即使光标在选区外。放大镜覆盖在标注工具条之上，放大画面实时跟随选区预览边线，颜色值旁提供小色块。仍可移动或缩放选区，按 C 复制光标颜色，M 复制区域尺寸；选择标注工具后收起取色信息，仍可按 C 复制原始快照颜色。复制成功后关闭浮层并回原应用。
- 选择 / 取消选择和无变化的编辑不占撤销步骤，也不会清空重做。绘制、移动、缩放、改样式、擦除、删除按实际编辑顺序撤销 / 重做；一次拖动只记一步，恢复出的标注自动选中，允许直接继续编辑或按 Delete / Backspace 删除。文字输入期间 Delete 只编辑文字。
- 深色单行主工具栏靠选区右下角，空间不足时移到上方或屏幕内。矩形 / 椭圆、直线 / 折线 / 箭头、马赛克 / 模糊按组组织；点选工具后展开独立属性条，不显示工具使用预览。参数条默认与主工具条左对齐，仅右侧空间不足时向左退让以保持屏幕内。
- 32 像素高的紧凑属性条提供填充 / 描边、两排小色块、与本机 Snipaste 相同的 macOS 原生调色盘（颜色轮、RGB / HSB 等滑杆、色板、图片调色、蜡笔、透明度与样本，确定后应用，取消不修改）、线宽指示（细线宽显示圆点，超过 12 pt 显示数值）、字号（线宽和字号均使用逻辑点 pt，按显示器倍率映射到导出图片）及文字粗体 / 斜体。每种标注工具独立保存当前颜色（包含透明度），关闭截图或重启应用后恢复；同一工具组的其他样式在本次编辑期间记忆。
- 荧光笔和效果笔刷支持在截图画面上滚轮调宽，并显示随宽度变化的画笔轮廓；水平或零滚动不改变宽度。滚轮、1 / 2 或 [ / ] 调整线宽；文字工具调整字号；支持可切换的黑 / 白对比色描边，随文字样式和撤销历史保留，并写入导出图片。Tab 切换直线 / 箭头，空格隐藏 / 显示工具栏；文字输入期间不会抢走这些按键。
- 宽度按钮持续选中，点击不弹菜单；在宽度按钮、截图画布或选区外遮罩上滚轮，每档调整 1 pt（工具栏其他按钮和留白不调宽），也支持 1 / 2、[ / ]。变化立即作用于选中标注及后续绘制，工具切换分别记忆参数。形状的描边宽度 / 填充、马赛克与模糊及橡皮擦的画笔宽度 / 框选均为互斥选项；填充和框选时不调整笔宽。点击按钮后焦点回到编辑器，保留撤销等键盘快捷键。
- 直线工具拖拽画直线，多次点按画折线，右键结束并提交折线。Shift 绘制正方形、正圆或 45 度线 / 箭头。右键结束当前工具并取消标注选中，回到选区调整模式；不会清除标注。
- 文字属性条可选择当前系统已安装的字体，菜单支持搜索，并按需构建可见项、使用各字体预览名称；安装了 Comic Sans MS 等字体后也可选择。字号提供 8–200 pt 预设，按显示器倍率映射到导出图片。字体与字号作用于当前输入、选中文字及后续文字，支持撤销 / 重做，预览与 PNG 导出保持一致。
- 文字直接在截图内输入，支持多行；⌘Enter 结束文字输入，Esc 放弃本次文字编辑。选中文字后可点击属性条的「编辑文字」重新修改。复制 / 保存时提交尚未结束的文字。
- 右键结束当前工具后，可点选、移动、缩放已有标注；最新标注也可直接拖动或拉四角。方向键逐截图像素移动，Shift + 方向键调整右 / 下边界。可拖动区域显示手形光标，拖动时握手，工具栏按钮显示指向手势。
- 橡皮擦支持框选擦除和画笔擦除，只擦掉经过区域内的标注像素，保留区域外笔迹和截图原图；画笔支持点擦、连续涂擦和大小调整。拖拽实时预览，松手后整次擦除记为一步撤销，可重做，擦过的位置可以继续绘制。原标注始终保留完整对象：切回对应工具后，悬停旧标注边缘可拖动整个对象，选中后拖角点可整体缩放。擦除区域固定在截图坐标上，不随原标注移动；移出后笔迹恢复，移入后按原操作顺序重新擦除。Esc 或取消拖拽不提交擦除；Delete / Backspace 删除选中，⌘Z / ⌘Y / ⇧⌘Z 撤销 / 重做，保留最近 64 步。
- 工具条不再提供「重新框选」。选区与标注独立：移动或缩放选区不改变标注在冻结截图上的位置和大小，不新增标注撤销步骤或清除重做；缩小可裁切标注，选区外部分仅隐藏，重新扩大后恢复。复制和保存只输出选区内内容。
- 「复制并完成」或 Enter / ⌘C 写入 PNG 剪贴板后结束；「保存 PNG」或 ⌘S 打开系统保存面板，成功后结束，取消面板则继续标注。文字输入期间的 ⌘C 按普通文本复制处理。
- Esc 退出截图，进行中的笔画 / 选区调整先取消；输出保持选区原始像素，不含工具栏、输入框、控制点或尺寸标签。
- 马赛克和高斯模糊均支持涂画与矩形框选；涂画可通过滚轮、线宽按钮或 [ / ] 调整笔刷宽度，支持单点涂抹。两种模式都保留效果强度滑杆，涂画时线宽由滚轮单独调整，不再并排显示两条滑杆；切换保留宽度和强度，强度滑杆提供 5 档，分别改变马赛克色块大小（约 4 / 8 / 12 / 20 / 32 像素）和高斯模糊半径（2 / 5 / 10 / 16 / 24 像素）；与笔刷宽度独立，选中已有标注后也能调整，支持撤销 / 重做，滑杆拖动时连续预览、松手后只提交一步历史。编辑画面与导出 PNG 共用渲染器。文字旋转等尚未实现。

没有项目、图片工作区、草稿恢复、打开 / 保存项目或文件关联。历史不承担编辑流程：取色和测量已经在屏幕上完成复制，历史仅用于回看或重新复制。取色历史默认最多 64 条，尺子历史默认最多 32 条；各自在工具设置中可选择 16 / 32 / 64 / 128 / 256 条。超过上限自动移除最旧记录，调低上限立即精简历史，旧数据启动恢复时也会精简并保存。尺子始终保留最新测量，其余优先保留收藏，但所有记录仍计入总上限：从其余记录中先移除最旧未收藏记录，没有时移除最旧收藏。截图历史只保留本次运行最近 12 张且合计不超过 64 MiB，退出应用后释放。旧版本留在用户磁盘上的文件不会被主动删除。

### 贴图

交互参考 Snipaste 的[基础操作](https://github.com/Snipaste/feedback/wiki/基础操作)与[内置快捷键](https://github.com/Snipaste/feedback/wiki/内置快捷键)。截图浮层点击「贴到屏幕」或按 `⌘T`，会提交正在输入的文字和折线，将当前选区连同标注贴到屏幕并结束截图，保留原位置与 Retina 逻辑尺寸，不改变剪贴板，也不自动打开主窗口。截图历史也提供贴图按钮。

从状态栏菜单、截图设置页或 `⌘⇧T` 可贴出系统剪贴板中的图片、纯文本或 HEX 颜色（`#RGB` / `#RRGGBB` / `#RRGGBBAA`）。贴图不需要录屏权限；空剪贴板或不支持的内容会明确报错。文字渲染为完整多行图片，颜色渲染为带色值的色卡。

- 多张独立 macOS 置顶窗口，可跨桌面与全屏应用显示；拖动移动，方向键每次移动 1 pt，Shift + 方向键移动 10 pt。
- 滚轮围绕指针缩放（5%–1600%），`⌘` + 滚轮调整不透明度（10%–100%）；`+` / `-` 缩放，`0` 恢复原始逻辑大小，`9` 适应屏幕。
- `1` / `2` 顺时针／逆时针旋转 90°，`3` / `4` 水平／垂直翻转；中键恢复原始大小、方向与不透明度，保留当前位置。
- `⌘C` 复制图片，`⌘S` 保存 PNG；导出保留完整原图像素和旋转／翻转结果，显示缩放和窗口透明度不影响导出。右键菜单提供同一组操作、不透明度预设与鼠标穿透。隐藏后恢复贴图会解除鼠标穿透，方便再次操作。
- `Esc` 或双击隐藏当前贴图；`Shift+Esc` / `⌘W` 销毁当前贴图。`⌘⇧V` 或状态栏菜单隐藏全部／恢复全部；也可销毁全部。两组全局快捷键均可在常规设置重新录制。
- 隐藏保留图像与变换状态，销毁释放资源；所有贴图仅保留到退出应用，不写磁盘、不恢复为项目或草稿。最多 32 张，总源像素不超过 6400 万；超限明确拒绝，不自动销毁已有贴图。显示器移除时将贴图移回可见屏幕。可见贴图会进入后续屏幕截图，隐藏贴图不会。

### 取色与测量

取色放大镜支持 4×–32×、滚轮切换倍率、方向键逐像素定位和连续取色。取色器页可选择 HEX / RGB / HSL / Flutter / CSS 等复制格式，旧的格式和历史偏好继续读取。旧版“先打开颜色编辑器 / 取色后回到编辑器”偏好统一走屏幕取色、当场完成。

设置组织参考 Snipaste 的[高级设置](https://github.com/Snipaste/feedback/wiki/Advanced-Configs)与[内置快捷键](https://github.com/Snipaste/feedback/wiki/Key-Bindings)，将仓库已有的鼠标动作和颜色输出模板开放到取色器页。中键、右键可独立选择复制并结束、连续取色或取消，左键仍由连续取色开关控制，Esc 始终退出。颜色格式支持新增、编辑、启停、排序和删除，始终保留至少一种启用格式；模板编辑实时预览并校验占位符。`%Re / %Gr / %Bl` 表示 RGB 通道，`%ReX / %GrX / %BlX` 表示两位大写十六进制，小写改用 `x`，`%%` 输出百分号。所有设置保存后立即生效并在重启后恢复。

测量同时显示截图像素 px 和 macOS 逻辑点 pt；根据每块显示器的两轴缩放换算。每个矩形选区限于一块显示器。松手后保留测量框和尺寸，默认支持多个框：拖框内移动、拖边角缩放，在空白处拖拽新增。方向键逐截图像素移动选中框，Shift + 方向键调整尺寸，选择测量框后，可点「删除测量框」或按 Delete / Backspace 删除，⌘Z / ⇧⌘Z 撤销 / 重做。⌘C 或「复制尺寸」复制当前框并保留浮层，Enter 复制当前框并结束，Esc 退出；可拖动的测量框悬停时显示手形光标，拖动时握手；可点击的工具栏按钮显示指向手势。图片输出统一使用截图工具，尺子工具条不再提供复制 / 保存图片、选框下拉框和仅编辑开关。自动测距以颜色容差识别连续边界，滚轮每档调整 15，范围 0–255；顶部容差输入框可直接输入整数，Enter 或离开输入框时确认，无效输入恢复原值。历史支持命名、收藏、筛选和 CSV / JSON 导出。

## 权限与数据

需要 macOS 14+。首次使用，在常规页请求屏幕录制权限，并按系统提示允许**实际运行的 fruler 应用**，必要时重启。拒绝授权时会显示明确提示，不会让历史页等待后续编辑步骤。

每次工具会话冻结屏幕快照，退出后释放，不持续录屏、不上传。只有主动复制或保存才输出图片。颜色、测量历史及偏好保存在本机；截图历史仅存在内存中。Debug / Release 的应用标识不同、可分别运行；同一标识只允许一个实例。Windows / Linux 尚未实现。

### 本机诊断日志

Dart 与 Swift 的诊断统一写入沙盒 Application Support 下的 `fruler/logs/fruler.log`，每 10 MiB 轮转，保留 3 份旧日志。使用 `logging` / `logging_appenders`，Debug 同时输出控制台；Release 默认记录 INFO 及以上。启动、权限、工具会话、快捷键、配置加载保存、导出与失败恢复均有诊断，Flutter、平台和异步未处理异常保留错误类型及堆栈。日志不记录截图像素、剪贴板正文、完整偏好 JSON 或用户文件名。

macOS 沙盒路径通常为 `~/Library/Containers/<应用标识>/Data/Library/Application Support/<应用目录>/fruler/logs/`；集成测试使用独立标识。Swift 通过类型化回调交给 Dart 单独写入和轮转，启动前暂存有界日志队列。日志目录不可写时应用继续启动；运行中写入失败则停用文件输出，避免错误递归。

### 界面语言

常规页可选择「跟随系统」「简体中文」或「English」，选择保存在本机，立即应用于窗口、截图标注、原生菜单与正在使用的工具浮层。跟随系统时，中文区域使用简体中文，其他语言使用英文。颜色 / 尺寸复制结果、导出 CSV / JSON 的字段和格式、用户命名不随界面语言变化。

Flutter 用户文本集中在 `lib/l10n/app_en.arb` 和 `app_zh.arb`，通过 `flutter --no-version-check gen-l10n` 生成类型化访问代码。原生文本位于 `macos/Runner/en.lproj` 与 `zh-Hans.lproj`。新增文案时同步补齐两种语言及参数；完整检查包含资源覆盖与占位符一致性检查。

## 开发与运行

当前本机验证 Flutter 3.47.7 / Dart 3.13.4 和 Xcode，Apple Silicon；Intel 尚未实机验收。

```sh
flutter --no-version-check pub get
flutter --no-version-check run -d macos
```

构建：

```sh
flutter --no-version-check build macos --release --no-pub
```

构建结果位于 `build/macos/Build/Products/Release/fruler.app`。分发给其他用户前仍需正式签名与公证。SDK 镜像缺少引擎文件时，可在单次命令前设置可用的 `FLUTTER_STORAGE_BASE_URL`；不需要修改全局设置。

## 原生通信协议

macOS 与 Flutter 使用 Pigeon 传递控制、事件和元数据，使用 Dart FFI 读取冻结的 sRGB RGBA 像素。协议源是 `pigeons/desktop.dart`：`DesktopHostApi` 定义 Dart → Swift 调用，`DesktopFlutterApi` 定义 Swift → Dart 回调；截图回复只包含缓冲句柄、长度、行跨度及显示器尺寸，不通过通道传整屏像素。文本复制继续使用 Flutter 标准 Clipboard 接口。

`NativePixelBuffer.swift` 提供稳定的 C ABI：`fruler_frame_acquire`、`fruler_frame_data`、`fruler_frame_length`、`fruler_frame_release`。原生会话持有初始缓冲，Dart 外部字节视图持有独立引用，最后一个视图被回收后由 native finalizer 释放。结束会话注销句柄，已有视图仍可安全读取；像素视图只读。其他桌面平台实现相同采集与缓冲接口即可复用 Dart 算法。

选区通过 `PixelFrame` 的原图、偏移和行跨度共享缓冲，取色和测距通过统一像素寻址访问。标注按原图缓存 `ui.Image`，调整和重新选择选区复用原图，预览与导出按源矩形绘制；PNG 仅在最终输出时编码。首次创建 Flutter 图片仍会复制到引擎缓冲并上传，不能视为全链路零拷贝。

修改协议后执行：

```sh
dart run pigeon --input pigeons/desktop.dart
```

生成的 Dart / Swift 文件一起提交；Pigeon 版本固定在开发依赖中。`python3 tool/check_protocol.py` 会重新生成到临时目录并检查一致性，完整检查已包含此步骤。`dev.fruler/integration` 是独立的测试驱动通道，只在 `FRULER_INTEGRATION_TEST` 构建中启用。

## 测试

新增 / 修复行为先补失败回归，再修改实现。单元和 UI 测试不能替代真实 macOS 通道与浮层验收；开发约束见 [AGENTS.md](AGENTS.md)。

```sh
python3 tool/check.py
```

完整门禁依次运行静态检查、单元 / UI、原生 PNG、跨进程单实例、原生 XCTest 和真实 macOS 集成测试。原生 XCTest 串行执行，避免共享单实例宿主、剪贴板和 AppKit 状态的测试进程互相干扰。任一步失败返回非零。也可单独运行：

```sh
flutter --no-version-check test --no-pub
python3 tool/test_macos_native.py
python3 tool/test_macos_integration.py
python3 tool/test_color_samples.py
```

集成测试使用独立的 `dev.fruler.integration` 标识和沙盒，需要本机允许录屏并保持桌面解锁。锁屏时 ScreenCaptureKit 可能返回空的显示器列表，不能作为验收通过。它实际调用 ScreenCaptureKit，向原生 NSPanel 发送 Cocoa 鼠标 / 键盘事件，检查：

- FFI 真实读取带行间填充的原生缓冲，原生注销 / 释放会话后旧像素视图仍有效，失效句柄和长度不符被拒绝；读取 isolate 退出后验证原生终结器释放最后一个引用。
- 选区前后窗口编号不变，主窗口始终隐藏；标注后调整选区仍在本次会话中。
- 九种标注工具、文字、撤销 / 重做，以及真实系统 PNG 剪贴板。
- 截图原位贴图、完整标注像素与 Retina 逻辑尺寸；剪贴板图片／文字／颜色，真实 Cocoa 拖动、滚轮、透明度、旋转翻转、重置、隐藏恢复与销毁。
- 取消保存面板继续标注；复制完成、Esc 取消、取色和测量结束后不重新打开主窗口。
- Swift 与 Dart 日志落入同一沙盒文件、真实退出握手刷新日志，以及未激活浮层的首次点击仍立即取色。
- 鼠标切换语言后 Flutter、原生菜单和现有尺子浮层同步更新，语言偏好通过真实原生存储恢复，剪贴板颜色格式保持一致。
- 从选项窗口用鼠标设置取色格式 / 倍率和尺子模式 / 容差，真实屏幕浮层接收同一配置，结束后主窗口继续隐藏，配置可重新载入。
- 通过原生存储精简超量的取色 / 收藏测量历史并恢复上限设置，真实 Cocoa 右键按自定义格式连续复制，中键取消不改变剪贴板。

颜色样本回归通过真实系统鼠标拖放保存色块、点击恢复，并启动第二个应用进程验证自定义色块及画笔当前颜色仍在；夹具需要辅助功能权限，测试前后备份和恢复系统颜色样本文件。

测试会备份和恢复剪贴板，外部 AppKit 夹具也会在退出时恢复启动前的剪贴板，以覆盖测试应用异常退出。没有录屏权限时，真实采集用例明确失败，不以跳过替代通过。输入驱动仅在 `FRULER_INTEGRATION_TEST` 条件下编译，普通 Debug / Release 不包含它。运行集成测试后，正常 `flutter run -d macos` 会重新构建普通应用。

UI 回归覆盖默认 1100×760、最小 920×680 和鼠标输入。跨显示器混合缩放、不同全屏应用及真实物理快捷键还应进行额外实机验收。
