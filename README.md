# fruler

macOS 屏幕取色、测量与截图标注工具。Flutter 负责历史、设置和标注界面，Swift 负责屏幕采集、浮层、快捷键与系统剪贴板。

## 使用流程

| 工具 | 默认快捷键 | 在屏幕上完成 |
| --- | --- | --- |
| 取色 | `⌘ ⇧ C` | 放大镜定位像素，点击 / Enter 立即复制；Esc 取消 |
| 测量 | `⌘ ⇧ R` | 拖拽后保留尺寸，可移动、缩放和新增选框；Enter 复制当前框并结束；1–4 切换模式 |
| 截图标注 | `⌘ ⇧ X` | 框选后直接在同一个全屏浮层、同一个位置标注，复制 / 保存成功即结束 |

完成后关闭浮层并回到原应用，不自动打开主窗口。主窗口只提供三个工具入口、取色 / 测量 / 截图历史，以及必要设置。菜单栏可随时启动工具，关闭主窗口后仍可使用全局快捷键。

### 截图与标注

- 选区确认后，标注图像保留屏幕中的原位置和尺寸；工具栏靠近选区显示。选区与标注使用同一个原生 NSPanel，不切换到主窗口。
- 矩形、椭圆、直线、箭头、画笔、荧光笔、文字、马赛克、高斯模糊。
- 紧凑图标工具栏，不显示工具使用预览；仅展开当前工具适用的颜色、线宽或字号。预设 / 自定义 HEX 颜色；选择后拖动标注或四角调整大小，方向键逐截图像素移动，Shift + 方向键调整右 / 下边界。
- 橡皮擦支持拖拽框选，松手后删除相交的整条标注，一次撤销可全部恢复；也支持点按删除最上层标注。Esc 或取消拖拽不删除；Delete / Backspace 删除选中；撤销 / 重做保留最近 64 步。
- 「重新框选」回到本次冻结快照重新选择，不重新录屏；取消当前标注。
- 「复制并完成」或 Enter / `⌘C` 写入 PNG 剪贴板后结束；「保存 PNG」或 `⌘S` 打开系统保存面板，成功后结束，取消面板则继续原位标注。
- Esc 退出截图；绘制中先取消当前笔画。图片按选区原始像素输出，不含工具栏、控制点或测量标签。
- 马赛克目前采用约 12 像素采样块，模糊强度固定；预览与 PNG 导出共用绘制逻辑。

没有项目、图片工作区、草稿恢复、打开 / 保存项目或文件关联。历史不承担编辑流程：取色和测量已经在屏幕上完成复制，历史仅用于回看或重新复制。截图历史只保留本次运行最近 12 张且合计不超过 64 MiB，退出应用后释放。旧版本留在用户磁盘上的文件不会被主动删除。

### 取色与测量

取色放大镜支持 4×–32×、滚轮切换倍率、方向键逐像素定位和连续取色。设置中可选择 HEX / RGB / HSL / Flutter / CSS 等复制格式，旧的格式和历史偏好继续读取。旧版“先打开颜色编辑器 / 取色后回到编辑器”偏好统一走屏幕取色、当场完成。

测量同时显示截图像素 px 和 macOS 逻辑点 pt；根据每块显示器的两轴缩放换算。每个矩形选区限于一块显示器。松手后保留测量框和尺寸，默认支持多个框：拖框内移动、拖边角缩放，在空白处拖拽新增。方向键逐截图像素移动选中框，Shift + 方向键调整尺寸，Delete 删除选中框，⌘Z / ⇧⌘Z 撤销 / 重做。⌘C 或「复制尺寸」复制当前框并保留浮层，Enter 复制当前框并结束，Esc 退出；仍支持带尺寸局部 PNG 输出。自动测距以颜色容差识别连续边界，滚轮每档调整 15，范围 0–255。历史支持命名、收藏、筛选和 CSV / JSON 导出。

## 权限与数据

需要 macOS 14+。首次使用，在设置中请求屏幕录制权限，并按系统提示允许**实际运行的 fruler 应用**，必要时重启。拒绝授权时会显示明确提示，不会让历史页等待后续编辑步骤。

每次工具会话冻结屏幕快照，退出后释放，不持续录屏、不上传。只有主动复制或保存才输出图片。颜色、测量历史及偏好保存在本机；截图历史仅存在内存中。Debug / Release 的应用标识不同、可分别运行；同一标识只允许一个实例。Windows / Linux 尚未实现。

## 开发与运行

当前本机验证 Flutter 3.47.7 / Dart 3.13.4 和 Xcode，Apple Silicon；Intel 尚未实机验收。

```sh
flutter --no-version-check pub get
flutter --no-version-check run -d macos
```

构建：

```sh
flutter --no-version-check build macos --release --no-pub
```

构建结果位于 `build/macos/Build/Products/Release/fruler.app`。分发给其他用户前仍需正式签名与公证。SDK 镜像缺少引擎文件时，可在单次命令前设置可用的 `FLUTTER_STORAGE_BASE_URL`；不需要修改全局设置。

## 测试

新增 / 修复行为先补失败回归，再修改实现。单元和 UI 测试不能替代真实 macOS 通道与浮层验收；开发约束见 [AGENTS.md](AGENTS.md)。

```sh
python3 tool/check.py
```

完整门禁依次运行静态检查、单元 / UI、原生 PNG、跨进程单实例、原生 XCTest 和真实 macOS 集成测试。任一步失败返回非零。也可单独运行：

```sh
flutter --no-version-check test --no-pub
python3 tool/test_macos_native.py
python3 tool/test_macos_integration.py
```

集成测试使用独立的 `dev.fruler.integration` 标识和沙盒，需要本机允许录屏。它实际调用 ScreenCaptureKit，向原生 NSPanel 发送 Cocoa 鼠标 / 键盘事件，检查：

- 选区前后窗口编号不变，主窗口始终隐藏；重新框选仍在本次会话中。
- 九种标注工具、文字、撤销 / 重做，以及真实系统 PNG 剪贴板。
- 取消保存面板继续标注；复制完成、Esc 取消、取色和测量结束后不重新打开主窗口。

测试会备份和恢复剪贴板。没有录屏权限时，真实采集用例明确失败，不以跳过替代通过。输入驱动仅在 `FRULER_INTEGRATION_TEST` 条件下编译，普通 Debug / Release 不包含它。运行集成测试后，正常 `flutter run -d macos` 会重新构建普通应用。

UI 回归覆盖默认 1100×760、最小 920×680 和鼠标输入。跨显示器混合缩放、不同全屏应用及真实物理快捷键还应进行额外实机验收。
